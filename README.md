# موقع المشرفة - الإشراف التربوي

مشروع متكامل لموقع الإشراف التربوي مجهز للرفع على GitHub Pages ومربوط بـ Google Sheets كقاعدة بيانات.

## محتويات الملف:
1. `index.html`: ملف الصفحة الرئيسية والمواجهات.
2. `Code.gs`: كود Google Apps Script للربط بشيت قوقل.

## طريقة التشغيل والرفع على GitHub:
1. قم بفك الضغط عن هذا الملف.
2. ارفع ملف `index.html` إلى مستودع (Repository) جديد في GitHub.
3. فعّل خاصية GitHub Pages من إعدادات المستودع ليعمل الموقع مباشرة.
4. انسخ كود `Code.gs` وضعه داخل Apps Script في قوقل شيت وقم بعمل Deploy كـ Web App، ثم انسخ الرابط وضعه داخل `index.html` في متغير `SCRIPT_URL`.
