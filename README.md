# موقع المشرفة - وحدة الإشراف التربوي (الخطة اليومية)

تم التحديث وإضافة شاشة الدخول وبنود الخطة اليومية وجلب أنواع الزيارات من Google Sheets.

## طريقة الاستخدام:
1. ارفع ملف `index.html` على GitHub repository وفعّل GitHub Pages.
2. أضف الكود الموجود في `Code.gs` داخل Apps Script لقاعدة بيانات Google Sheet.
3. أنشئ ورقة باسم `VisitTypes` وضعي فيها أنواع الزيارات في العمود الأول ليتم جلبها في القائمة المنسدلة تلقائياً.
4. تأكد من عمل Deploy كـ Web App وانسخ الرابط لضعه في ملف `index.html` بدلاً من `SCRIPT_URL`.
